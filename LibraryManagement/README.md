# Library Management System
A console-based library management system written in C++.

## Features
- Manage readers, books, and borrowing tickets.
- Calculate expiration dates, return dates, and late fees.

## How to Build and Run
1. Install CMake and a C++ compiler (e.g., g++).
2. Navigate to the project directory.
3. Run:
   ```bash
   mkdir build
   cd build
   cmake ..
   make
